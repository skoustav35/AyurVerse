# 2026-09-18

## README rewrite (full documentation pass)

Rewrote `README.md` from ~170 lines of internal shorthand into ~770 lines of contributor-facing documentation. Kept the author's existing voice/energy as a short intro blockquote, then added structure.

**Codebase facts established during the analysis** (useful for future doc work):

- **Real stack**: Vite 7 + React 19 + TS 5.9 strict + Tailwind v4 + Framer Motion + Zustand + TanStack Query 5 + React Router 7.
- **Data plane is Firebase, not Supabase.** Project `ananta-ayurverse`. The old README still described two Supabase projects and a `db/indexes.sql` + `db/rls-policies.sql` lockdown. Reality: `api/db-client.js` is a Postgres-shaped query-builder (`QB` class) executing against Firestore, with Admin SDK (writes) or Firestore REST + publishable key (anonymous reads only). `src/lib/firestore-db.ts` is the client lane. `src/lib/supabase.ts` is a Supabase-*shaped* facade over Firebase Auth; `supabase.from()` throws by design and channels are inert no-ops.
- **39 files in `api/`**, but only 31 are Vercel route handlers calling `enterScope(req)`. The 8 that don't: `auth-config`, `blob-store`, `db-wake`, `env`, `media`, `notify`, `opencode`, `storage-client` (helpers — `media` is a GET-only handler that legitimately skips it). The "every route starts with enterScope" invariant is accurate but not literally universal.
- **`vendor/` is survivability machinery, not used on a normal clone.** It only contains `package.json` + `package-lock.json` (no `node_modules/`), and `vite.config.ts` gates its aliases on `fs.existsSync(vendor/node_modules/<pkg>)`. `tsconfig` puts `node_modules/` first in paths. Safe to tell contributors to ignore it.
- **Numeric entity ids + string user ids.** Routes `parseInt()` ids; doc ID = `String(numeric id)`; `counters/{collection}` transactions mint the next id. Auth uids stay strings.
- `scripts/local-server.mjs` is the full-stack local run (serves `dist/` + executes real `api/*` modules in-process). Plain `npm run dev` does NOT run API routes.
- Society harness: Python, `httpx` only, `bots/.env.example` exists and documents every knob.

**Decision**: documented what the code actually does rather than what the old README claimed. Called out the Supabase→Firebase migration explicitly so the next reader isn't misled by `docs/SECURITY.md` / `docs/SCALING.md`, which still describe the Supabase RLS era.
